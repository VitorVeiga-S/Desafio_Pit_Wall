# Projeto Pit-Wall

Projeto desenvolvido como atividade prática de HTML e CSS, com o objetivo de recriar uma página temática do Grande Prêmio de São Paulo de Fórmula 1, realizado no Autódromo de Interlagos.

## Visão Geral do Projeto

O Pit Wall é uma página web inspirada no universo da Fórmula 1, desenvolvida com foco na reprodução visual de uma página de divulgação de um evento automobilístico.

O projeto apresenta:

1. Banner principal com informações sobre o GP de São Paulo.
2. Grid de pilotos com seus respectivos números e equipes.
3. Tabela de classificação com posições, vitórias e pontuação.
4. Área de ingressos com informações sobre setores e valores.
5. Formulário para preenchimento de dados e reserva de ingressos.
6. Layout responsivo para adaptação a dispositivos móveis.

## Estrutura do Projeto

- `index.html` — estrutura principal da página.
- `styles.css` — estilização e responsividade.
- `img/` — armazenamento das imagens utilizadas no projeto.
